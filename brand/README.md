# Amanfold brand

The source for Amanfold's visual identity. Everything here is generated by the scripts in `tools/`, so the logo, app icons, UI icons and design tokens stay in sync.

Open `guide/index.html` in a browser for the full brand guide (logo use, colour, type, voice and tone, icons, interface basics and sample screens).

## The mark: Letterlock

A square sheet with its four corners folded to the centre and closed with a saffron seal. Before envelopes, people folded letters shut so that any tampering showed (historians call it letterlocking). *Aman* (أمان) is Arabic for safety.

## What's here

| Folder | Contents |
| --- | --- |
| `logo/` | Mark and lockups (Latin, Arabic, stacked) in colour, reversed, black and white; SVG plus PNG in `logo/png/` |
| `app-icon/` | Store icon (full-bleed 1024), rounded preview, Android adaptive + themed layers, `favicon.svg`, `favicon.ico`, PNGs 16–1024 |
| `icons/` | 24 UI icons (24 grid, 1.75 stroke, round caps) and `sprite.svg` |
| `tokens/` | `tokens.css` (CSS variables, light and dark) and `tokens.json` |
| `guide/` | The brand guide page |
| `tools/` | Build scripts |

## Quick rules

- **Colour:** Oasis 800 `#0F3B3A` is the brand colour; Saffron 500 `#E9A23B` is the seal. Outside the logo, saffron appears at most once per screen. Never use Saffron 500 for text on light backgrounds (use Saffron 700 `#A2661A`).
- **Type:** Readex Pro (display, Latin and Arabic), IBM Plex Sans + IBM Plex Sans Arabic (interface), IBM Plex Mono (passwords and codes). All SIL Open Font License, all on Google Fonts.
- **Logo:** clear space equals the seal's diameter; mark minimum 16 px, lockup minimum 96 px wide. Don't rotate, recolour, stretch, or add padlocks and shields.
- **Voice:** calm, plain, honest about limits, equal in every language. Tagline: *Everything you keep, safely folded.* / *كل ما تحفظه، مطويٌّ بأمان.*

## Rebuilding

```sh
pip install fonttools uharfbuzz pillow
python brand/tools/build.py      # logos, app icons, tokens (downloads Readex Pro on first run)
python brand/tools/icons.py      # UI icons
node brand/tools/render-png.js   # PNG exports (needs Playwright)
python brand/tools/favicon-ico.py
python brand/tools/guide.py      # brand guide page
```

Change colours in `tools/palette.py` and the mark geometry in `tools/build.py`, then rebuild.
